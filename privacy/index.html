Privacy Policy

Last Updated: July 25, 2026

1. Information We Collect

The Bot may store information required for its features:

  • Discord User ID
  • Discord Server ID
  • Channel IDs
  • Role IDs
  • XP and leveling data
  • Economy balance
  • Voice activity statistics
  • Bot configuration settings

2. Message Data

If message logging is enabled by a server administrator, the Bot may process:

  • Deleted messages
  • Edited messages
  • Attachments
  • Links
  • Media information

3. How Data Is Used

Data is used only for providing Bot features:

  • Moderation logs
  • Server statistics
  • Leveling system
  • Economy system
  • Role management

4. Data Sharing

We do not sell, rent, or share user data with third parties.

5. Data Storage

Data is stored securely and kept only while required for Bot functionality.

6. Data Deletion

Server owners may request deletion of stored server data.

7. Security

Reasonable measures are used to protect stored information. However, no online service can guarantee complete security.

8. Changes

This Privacy Policy may be updated in the future.

9. Contact
